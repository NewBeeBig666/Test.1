## 2. 已实现的真实接入

### 2.1 MovieTweetings（电影域 · 92 万真实评分，已实测接入）

```bat
cd recommender
py -3 dataset_channels.py --update --channel movietweetings   # 下载 + 标准化 -> data/external/movietweetings
py -3 dataset_channels.py --merge-movies                       # 与 MovieLens 按 IMDb ID 合并
```

- 下载：`ratings.dat / movies.dat`（userId::imdbId::rating(1-10)::ts 格式，27.6 MB + 2.0 MB）
- 标准化：`ratings.csv(orig_user_id, item_orig, rating)` + `items.csv(item_orig, title, subtitle=genres, extra=year)`，共 **921,398 评分 / 38,018 部电影 / 71,707 用户**
- 合并（实测结果）：经 MovieLens `links.csv` 的 IMDb ID 关联，**666,685 条 MT 评分（72%）可映射到 MovieLens 电影**，输出完整域格式 `data/processed_movies_merged/`：**700,228 评分 / 19,640 用户 / 7,024 物品**（MovieLens 100,836 + MT 666,685，复用 `preprocess_domain.clean_and_split`）
- **不影响已验证的主模型**；启用合并数据只需将 `api.py` 的 `DOMAINS["movies"]` 指向 `data/processed_movies_merged` 并重启（评估用 `py -3 evaluate_all.py` 重跑即可对比合并前后效果——可作为论文"多源数据整合"实验）

### 2.2 Project Gutenberg（图书域 · 公版书元数据）

```bat
py -3 dataset_channels.py --update --channel gutenberg
```

官方全量书目目录（pg_catalog.csv）→ 过滤英文 Text → `items.csv(item_orig, title, subtitle=作者, extra=类目)`，作为图书域**内容增强型**渠道（无个体评分，不并入评分矩阵，可扩充物品目录与 TF-IDF 词表）。

## 3. 自动化更新机制

| 层级 | 机制 |
|---|---|
| 手动 | `py -3 dataset_channels.py --update`（全部 adapter 渠道：下载→解析→统一格式→触发质量报告） |
| 一键脚本 | 根目录 `update_datasets.bat`（更新 + 质量报告） |
| 定时任务 | `schtasks /Create /SC DAILY /TN RecSysDataUpdate /ST 03:00 /TR "E:\ZcodeSpace\New Demo\update_datasets.bat"`（每日 03:00 自动执行） |
| 新渠道扩展 | 在 `CHANNELS` 注册表登记（id/url/字段/状态），实现 `update_{id}()` 适配器并加入 `ADAPTERS`，即纳入 `--update` 与质量监控 |

## 4. 数据质量监控体系

`py -3 dataset_channels.py --quality` → `reports_all/data_quality.md`，监控维度：

1. **完整性**：主模型三域 + 外部渠道的行数 / 用户数 / 物品数 / 元数据量
2. **分布健康**：评分均值、评分归一化区间、稀疏度（检测异常漂移）
3. **时效性**：各数据文件最近更新时间（数据新鲜度）
4. **异常告警**：与上次基线（`data/external/last_quality.json`）自动对比，行数骤降 >5% 触发告警（数据源故障 / 下载不完整的信号）
5. **渠道可用性**：注册表全部渠道的接入状态汇总

## 5. 与主系统的关系

- 主模型（三域推荐 + 跨域 + 评估）数据源不变，外部渠道为**扩展层**，不影响已验证的推荐与实验结果
- 需要启用某外部渠道进入推荐模型时：评分型渠道按第 2.1 节方式生成完整域目录（或并入既有域的 `ratings_all.csv` 后重跑 preprocess / evaluate_all）；元数据型渠道并入 items 元数据以增强内容特征
- 质量报告同时是论文"数据渠道整合与质量监控"章节的素材来源

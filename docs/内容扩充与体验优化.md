## 1. 课程封面完善（程序化设计，2205 张）

`generate_course_covers.py`（Pillow）为全部课程生成真实 PNG 封面文件：

| 项 | 说明 |
|---|---|
| 尺寸 | **1200×1600 PNG**（3:4 匹配卡片；宽 1200 ≥ 1080、高 1600 ≥ 720） |
| 设计模板 | 平台课程绿主渐变（与 `--courses` 设计令牌一致）+ 类目辅助色光晕 + 几何视觉元素（代码括号/图表/音符/画笔，纯矢量绘制） |
| 内容元素 | 课程标题（自适应换行排版 + 字号收缩）、类目标签胶囊、底部「难度 · Udemy」信息条 + 学习人数 |
| 字体 | Windows 内置 Segoe UI Bold（英文）/ 微软雅黑（中文），无版权问题 |
| 产出 | `recommender/data/covers/courses/{id}.png`（2205 张，227MB），经 `/covers/**` 静态映射服务（`app.covers-dir`，绝对路径 URI） |

失败回退链：Udemy 平台无公开封面 API（服务器端 403）→ 程序化设计封面 → 前端渐变排版卡兜底。实测 `/covers/courses/{id}.png` 200 响应 78ms，浏览器 12/12 卡片加载成功。

**版权合规**：图书全部为 Gutenberg 公版（source_url 指向官方阅读页）；电影为 MovieLens 目录元数据引用（区域片单严格年份匹配，防止错配翻拍版）。

**交互联动**：环球页电影点击 → `/movies?open={itemId}` 应用内跳转并自动打开详情抽屉（海报/简介/IMDb 外链/评分/收藏/推荐全联动）；图书点击 → `/away` 过渡页前往 Gutenberg 阅读页。

**数据说明（如实）**：MovieLens ml-latest-small 不含部分经典影片（如东京物语、老男孩韩版原始数据未收录则按实际目录为准）；日韩书籍为英译公版本（原文版权或未公版）；课程域公开渠道无版权合规的多国评分数据，暂以区域化的图书/电影扩充为主。

## 3. 外部跳转体验优化（/away 统一过渡页）

替换原"确认对话框 + 直接 window.open"为**平台内过渡页**（`AwayView.vue`）：

| 要求 | 实现 |
|---|---|
| 统一加载界面 + 状态指示 | SPA 路由即时渲染（**零白屏**）+ 旋转加载动画 + 目标域名徽章 + 内容标题 |
| 布局可读 / 字体适中 | 苹果风居中卡片（26px 标题/15px 正文/14px note），径向渐变背景 |
| 响应式 | `max-width: 520px` + 移动端 padding 收缩 |
| 返回平台导航 | "返回平台"按钮（router.back）+ 倒计时自动返回 |
| 加载速度 | 3 秒倒计时进度条自动新窗口打开（`noopener,noreferrer`）；"立即前往"手动按钮；含弹窗拦截提示文案 |
| 风格一致 | 复用平台设计令牌（毛玻璃导航保留/accent 蓝/圆角/按钮体系） |

## 4. 电影海报覆盖率（补充实测）

首轮预取 2567/3650（70.3%，全部通过分辨率审核：宽≥300、比例 0.45~1.8；中位宽 1012px、1114 部宽≥1080）。
修复含外文括注标题（如 "Crouching Tiger (Wo hu cang long)"）的检索匹配后补跑缺失项；
仍未匹配的生僻条目（约 10%）回退渐变卡并列入 `reports_all/cover_audit.md` 供管理后台补充。
质量审核报告含覆盖率/分辨率分布/失败清单三部分。

## 5. 与现有系统的兼容性

- 新增能力均为增量：`world_content` 表独立于推荐域（`/api/world` 只读）；课程封面写入既有 `course.poster_url` 列；`/covers` 为公开静态资源（不占 jar 体积，文件系统直读）
- 推荐链路无新增请求：封面 URL 为 DB 字段透传（推荐 27~46ms 不变；封面图 78ms/张，懒加载）
- 数据更新机制：`update_datasets.bat` 已含海报增量补充（断点续传）；世界内容库可重跑 `build_world_regions.py` 刷新
